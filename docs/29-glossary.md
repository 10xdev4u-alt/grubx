# Glossary

Terms used in this documentation.

- **Bootloader:** The first program that runs when a computer starts.
- **Distro:** Distribution (e.g., Ubuntu, Arch).
- **EFI:** Extensible Firmware Interface (Successor to BIOS).
- **GRUB:** GRand Unified Bootloader.
- **Kernel:** The core of the OS.
- **Mount Point:** Where a partition is accessible in the file system (e.g., `/boot`).
- **PF2:** The font format used by GRUB.
- **Resolution:** The number of pixels (Width x Height).
- **Root:** The superuser (Administrator).
- **Terminal:** The command line interface.
