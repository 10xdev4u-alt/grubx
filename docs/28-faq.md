# FAQ

Frequently Asked Questions.

**Q: Will this slow down my boot?**
A: Marginally. Loading a 1080p image takes a fraction of a second. If you have a slow HDD, maybe. On SSD, it's instant.

**Q: Can I use a GIF?**
A: No. GRUB does not support GIFs.

**Q: I deleted the theme folder and now I can't boot!**
A: You need to edit the config from the GRUB CLI or a Live USB. See "Debugging Boot Issues".

**Q: Does this work on Kali Linux?**
A: Yes, hacker. It works on Kali.

**Q: How do I change the font size?**
A: You must generate a new font file using `grub-mkfont` with a larger size parameter.
