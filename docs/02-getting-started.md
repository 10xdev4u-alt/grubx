# Getting Started

Before installing PrinceTheme, ensure you have the following.

## Prerequisites

### 1. A Linux System
PrinceTheme works on almost any Linux distribution:
- Ubuntu / Debian
- Arch Linux / Manjaro
- Fedora / CentOS
- OpenSUSE

### 2. GRUB Installed
Most Linux systems come with GRUB pre-installed. You can verify this by checking for the file:
`/etc/default/grub`

### 3. Root Access
You need `sudo` privileges to modify boot files. **Be careful!** Incorrect changes can prevent your system from booting.

### 4. Screen Resolution
Ideally, your monitor should be 1920x1080 or higher for the best experience, though PrinceTheme scales to fit.

## Tools You Might Need
- A terminal emulator
- A text editor (nano, vim, VS Code)
- `git` (to clone this repo)
