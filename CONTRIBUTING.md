# Contributing to PrinceTheme

Yo Bro! Glad you want to help take this theme to the next level! 🚀

## How to Contribute
1. **Fork the Repo:** Click that fork button!
2. **Clone it:** Get the code on your machine.
3. **Branch:** Create a new branch (`git checkout -b feature/AmazingFeature`).
4. **Commit:** Commit your changes (`git commit -m 'Add some AmazingFeature'`).
5. **Push:** Push to the branch (`git push origin feature/AmazingFeature`).
6. **Pull Request:** Open a PR and let's review it!

## Guidelines
- Keep the design clean and minimal.
- Test your changes using `grub-emu` if possible.
- Update the documentation if you change anything major.

Let's build the best GRUB theme ever!
